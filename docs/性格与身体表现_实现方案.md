## 0. 一句话总纲

**不写死「猪的类型」。** 只定义 6 个性格维度（各 0..1）；每个维度去**抬高/压低若干「行为驱动(Drive)」的权重**；行为按权重竞争，个体差异自然**涌现**——有的扎堆成群、有的独来独往、有的见谁都怕、有的天不怕地不怕。

## 1. 性格系统（定义与生成）

- 6 维（与《雨世界》官方一致，各 0..1）：**攻击性 aggression / 勇气 bravery / 强势性 dominance / 活力 energy / 焦虑 nervous / 同情心 sympathy**。
- **生成**（出生时确定为个体状态）：
  - 方案 A｜纯随机：各维独立 `randfn(0.5, spread)` 截断 0..1。
  - 方案 B｜雨世界式（建议）：`bravery/energy/sympathy` 独立随机但**中间值少见**（PushFromHalf）；`aggression/dominance/nervous` 由它们**关联推导**（攻击偏低压、强势偏中、焦虑偏极端）。→ 个体差异有内在逻辑。
  - 用**个体种子**生成，可复现、便于存档（将来可换成父母基因+变异）。
- **存放纪律**：性格值 = 个体状态 → 放**组件**；维度定义/分布 = 数据 → 放 **Resource**。都不进 Creature 基类。
- 新建：`personality_def.gd`(Resource) + `personality.gd`(组件) + `creature/data/trait_*.tres`(6)；`CreatureDef.personality` 接线；猪用 `pig_temperament.tres`。

## 2. 六个维度各驱动什么（核心表）

| 维度 | 高值行为倾向 | 低值行为倾向 | 依据（雨世界） |
|---|---|---|---|
| **攻击性** aggression | 主动逼近/驱赶他人、抢食、容忍度低 | 与世无争、退让 | 高攻击更常攻击、更致命；低攻击更爱退让 |
| **勇气** bravery | 不惧未知、敢靠近、受伤仍坚持 | 易惊、逃、躲 | 高勇气更爱调查未知声、更少恐惧；低勇气更易惊 |
| **强势性** dominance | 当领队、占中心位、低强势者让路 | 跟随、避让、退到边缘 | 高强势当 pack leader；低强势更爱跟随领袖 |
| **活力** energy | 走动频繁、探索广、爱互动 | 多休息、原地磨蹭 | 高能量更爱动/玩；低能量多睡 |
| **焦虑** nervous | 易紧张、独处/受伤就慌、爱黏同伴求安全 | 淡定 | nervous 高更爱紧贴、更易受惊 |
| **同情心** sympathy | 亲近同伴、不驱赶、愿意聚集 | 冷淡、各过各的 | 高同情降低攻击、更温和 |

> 关键：**同一种「怕」，高勇气猪表现成「警惕地盯着」，低勇气猪表现成「掉头就跑」**——行为由维度组合决定，不是单维查表。

## 3. 群居 / 独行 / 鱼群效应（社交系统）

**派生量：合群度 sociability**（占位权重）
```
sociability = w1·同情 + w2·焦虑 + w3·(1−攻击) − w4·强势
```
- 为什么这么配：同情高→本就爱群；焦虑高→为安全感贴群；攻击高→不容忍旁人→减分；强势高→要当头而非融入→略减。

**群居（高合群度）**= 经典 boids 三力（格子化）：
- **凝聚**：朝邻近猪的重心走。
- **对齐**：跟上邻居的平均朝向（个体记 `last_dir`）。
- **分离**：不挤同一格（现有「不重叠」已覆盖一半）。

**独行（低合群度）**：主动**远离**最近的邻居 + 大范围游荡；若同时**高攻击+高强势** → **领地式驱赶**（把靠近的低强势猪挤开）。

**鱼群效应**：高合群度个体互相牵引 → 出现「一群猪朝同方向同步挪动」的现象，**纯涌现**、无脚本编排。焦虑高的群居猪尤其明显（贴群求安全）。

**必需的感知**：新组件 `Perception` —— 扫网格半径 R 内的邻居（格子有 `cell.content`，扫描很便宜）。它同时是将来「看见捕食者」的基础。

## 4. 惊慌（**收窄为高焦虑个体的行为**，不再当通用示例）

- 触发条件：个体**应激 stress 上升**（当前来源：自身受伤/出血；将来：看见捕食者、落单）**且** `易惊慌度 = 焦虑 ×(1−勇气)` 越阈值。
- 结果：**只有「高焦虑 + 低勇气」的猪会血少了乱跑**。
  - 高**勇气**个体受伤 → 反而继续领队、硬扛。
  - 高**同情**个体受伤 → 去找同伴靠拢。
  - 低**焦虑**个体受伤 → 照常活动，只是慢下来。
- 惊慌行为：**乱跑**（走格间隔骤减 + 频繁变向）；同时抬高通用 `Creature.exertion` → `Body` 出血液 ×(1+exertion·k)（**动得越猛伤口出得越快**）。
- 表现：惊慌猪图标抖动/闪烁（灰白像素风）+ 面板标注「惊慌」。

## 5. 行为驱动清单（架构：性格怎么变成动作）

每个「驱动」产出**期望方向/动作 + 权重**；Brain 每决策 tick **加权融合** → 在空闲方向里挑最贴近的一个走。

| 驱动 Drive | 何时起作用 | 权重来源 |
|---|---|---|
| Wander 游荡 | 永远 | 活力（高活力更频繁/更远） |
| Social 合群 | 附近有同类 | 合群度 |
| Separate 独处/避让 | 附近有同类 | (1−合群度)，攻击性高→转为驱赶 |
| Rest 休息 | 疲惫 | 1−活力 |
| Fear 惊恐 | 应激高 | 焦虑 ×(1−勇气) |
| Forage 觅食（future） | 饥饿 | 饥饿 |

- 融合：`desired = Σ(weight_i · dir_i)`，取与 desired 夹角最小的**可行**方向（不越界/不重叠，复用 GridMover）。
- **好处**：加新行为 = 加一个驱动 + 权重，不动其他代码（延续组件化纪律）。
- **升级点**：现有 `WanderBrain` 升级为「权重融合的 Brain」（或拆出 `SocietyBrain`/`PanicBrain` 作为驱动）。为了不返工，建议**直接改成融合式 Brain**。
