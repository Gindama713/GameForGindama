## 0. 核心洞察（不变）
主角 = `creature/player/` 下一个挂 `PlayerBrain` 的 `Creature`；`Brain` 换成读输入，`Body/Needs/Aging/Personality/GridMover` 全复用。加狼=建 `creature/wolf/`，加主角=建 `creature/player/`，同一套框架。

**两条白捡红利（读码确认）：**
1. **def 身份即隔离**：`Perception.neighbors()` 与 `Reproduction._find_mate()` 都按 `cr.def == creature.def`（同一 Resource）过滤同类。主角用独立 `player_def.tres` → 野猪既看不见他（不进猪群、不选他当配偶），**零 `is_player` 特判**。⇒ 因此主角**可以带 `Lineage`（性别）而不怕被繁殖**（见决策4）。
2. **伤病自动生效**：移动最终走 `GridMover.can_move()`（遍历各组件 `allows_movement()`），断腿/全断的否决链现成。

## 4. 移动速度模型（决策1 的核心，新增）

**统一一个" locomotion_speed ∈ [0,1]"**，谁想改移动速度就实现协议 6 `move_speed_factor()`，基类相乘聚合，**不点名具体组件**：

```
# creature_component.gd（协议 6，默认不减速）
func move_speed_factor() -> float: return 1.0

# creature.gd（聚合，与 visual_scale/is_concealed 同构）
func locomotion_speed() -> float:
    var s := 1.0
    for comp in _components.values():
        s *= comp.move_speed_factor()
    return clampf(s, 0.0, 1.0)
```
各组件贡献（乘起来）：
- **Body**：有 stance 肢体时 `= 存活stance / 总stance`（四条腿断两条→0.5；全断→0，且 `allows_movement` 已先否决）。无 stance（鱼/蛇）→1。
- **Needs（疲劳）**：`= lerp(FATIGUE_SLOW, 1.0, fatigue_ratio)`，`FATIGUE_SLOW≈0.55`（累到 0→五成半速）。
- **Aging**：`= 1 / speed_factor()`（幼 0.62 / 老 0.77 / 成 1.0）。

**PlayerBrain 步频**：`gate = def.move_interval / max(locomotion_speed, 0.15)`；`locomotion_speed≈0` 或 `GridMover.can_move()==false` → 不走。
→ 按住方向时：**满状态≈0.5s/格（2026-09-20 由 0.8 提速 1.6×）；累/断腿/老幼 → 明显变慢；全断 → 原地不动**。这就是"连续但看速度"。
> 说明：AI 的 `Brain` 暂不改（守最小改动），仍用它自己的疲劳/能量算间隔；将来可统一走 `locomotion_speed()`。

## 5. PlayerBrain 逻辑（读全局 Input，不碰场景树回调）

```
class_name PlayerBrain extends CreatureComponent
const HOLD_MOVE := true
var _step_acc := 0.0
var _prev := Vector2i.ZERO
var _intent := PlayerIntent.new()

func requires() -> Array: return [GridMover]

func tick(dt):
    _step_acc += dt
    var dir := _read_dir()                       # Input.get_vector → 主轴 → GridMover.DIRS 之一
    if dir == Vector2i.ZERO: return
    var speed := creature.locomotion_speed()
    var gate := creature.def.move_interval / maxf(speed, 0.15)
    var fire := (_step_acc >= gate) if HOLD_MOVE else (dir != _prev and _step_acc >= gate)
    if fire:
        _intent.submit(dir)
        _intent.apply(creature)                  # 干扰层挂点（v1 直通）
        var mover := creature.get_component(GridMover) as GridMover
        if mover.try_step(_intent.dir): _step_acc = 0.0
    _prev = dir

func debug_state(): return "玩家 输入=%s 速度=%.2f" % [dir_name(_read_dir()), creature.locomotion_speed()]
```
- 4 向映射：`var v := Input.get_vector("move_left","move_right","move_up","move_down")`，取 |x|,|y| 大的一轴映射到 `GridMover.DIRS`。
- 走不动时 `try_step` 返回 false（越界/被占/`can_move` 否决）→ 不重置计时，下一帧重试（与 Brain 容错风格一致）。

## 6. 相机软跟随（决策5）

```
# camera_rig.gd
var target: Node2D = null
const FOLLOW_DAMP := 8.0        # 越大越紧跟
const DEADZONE_PX := 6.0        # 小于此位移不动，防亚像素抖动
func set_target(t): target = t
func _process(delta):
    if target != null:
        var want := target.position
        if position.distance_to(want) > DEADZONE_PX:
            position = position.lerp(want, 1.0 - exp(-FOLLOW_DAMP * delta))
        _clamp_position()
        return                  # 跟随态：不吃键盘（WASD 归玩家）
    # 无 target 才走原来的手动 WASD 平移（保留兼容/自由镜头）
```
滚轮缩放（`_zoom_at_mouse`）、中键拖动保留；跟随态下键盘平移让位给玩家移动。`main` 生成主角后 `camera.set_target(player)`。

## 11. 风险
- **抢键**：跟随态让出 WASD 给玩家（§6 已处理）。
- **误入繁殖**：主角独立 def（野猪看不到）+ 不挂 Reproduction → 双保险；带 Lineage 只为性别/身份。
- **PlayerBrain 与 Brain 并存**：`player_def` 只挂 PlayerBrain，否则两套决策抢 `coord`。
- **速度模型两处并存**：AI `Brain` 暂留旧算法，主角走 `locomotion_speed`；将来统一（记 TODO，别现在改 Brain）。
- **character.png 尺寸/缩放**：`_render` 按 `CELL_SIZE/texture.width` 缩放，若 character 非 512 方图需确认比例；NEAREST 已全局。
